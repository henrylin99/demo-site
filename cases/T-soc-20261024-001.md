# Hacker News 头部越来越"卷"了吗：一次用官方 API 的跨年门槛检验

> 研究线 T-soc-20261024-001 · fde-soc-01 · 数据源：HN Algolia 官方搜索 API（无需鉴权，单请求可复验）

## 现象

内容平台运营方反复问一个问题：站内热度是更集中还是更扁平？Hacker News 的
得分数据通过官方 API 完全公开，是少数可以严肃检验这个问题的社区。我们按年
拉取得分 Top1000 故事：2015 年 Top1000 故事：门槛分 364、中位数 484、榜首 2228、Top10 得分占比 3.2%、基尼系数 0.200；2018 年 Top1000 故事：门槛分 498、中位数 658、榜首 6015、Top10 得分占比 3.8%、基尼系数 0.201；2021 年 Top1000 故事：门槛分 611、中位数 796、榜首 4103、Top10 得分占比 3.6%、基尼系数 0.200；2024 年 Top1000 故事：门槛分 538、中位数 722、榜首 4549、Top10 得分占比 3.7%、基尼系数 0.218 [E_obs]。

## 假设

预注册假设：进入年度 Top1000 的门槛分显著上升（升幅 ≥50% 判"头部竞争持续
加剧"），并用中位数口径与逐年单调性做独立复现 [E_pred]。

## 检验

主检验：门槛分（Top 榜最后一名得分）2015 年 364 → 2024 年
538，升幅 47.8% [E_main]。稳健性：中位数同期
484 → 722（升幅 49.2%），Top10
得分占比 3.2% → 3.7%，基尼系数
0.200 → 0.218，门槛分逐年单调抬升=False
[E_rob]。

## 评审

评审席以中位数口径独立复算并与主口径对方向：一致
[E_review]。终审裁决 not_supported——头部门槛通胀（若成立）的同时 Top10 占比与
基尼变化有限，说明"通胀"主要体现在进入门槛而非绝对集中度。

## 局限

API 单次上限 1000 条，长尾不可见，结论仅限头部口径 [E_lim]；门槛上升不能
区分内容质量提升与热度机制变化；样本年为离散抽样（2015、2018、2021、2024），复现以当次
拉取为准（2026-10-24 10:09）。
